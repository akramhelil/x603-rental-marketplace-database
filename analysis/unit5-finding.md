# Unit 5 Leadership Finding

## Recommendations

The platform has two groups of properties that need different responses. The first group includes properties that
receive viewing activity but have unusually high dispute rates. Property ID **1** had 2 disputed viewings out of 11,
Property ID **3** had 2 out of 13, and Property ID **5** had 2 out of 18. These properties should receive a focused
quality review. The Property Operations Manager should examine their disputed viewings, contact the renters and listing
managers when appropriate, and look for repeated problems with scheduling, listing accuracy, property condition,
amenities, or the viewing process. These properties are attracting renters, so the goal is to understand and reduce the
problems occurring during those interactions.

The second group includes Property IDs **14** and **15**, which have no recorded viewing events. These properties should
not be treated as successful listings with zero failures because there is no activity on which to judge their
performance. They need an activation and visibility review rather than a dispute review. The team should confirm that
each listing is available, visible in renter searches, accurately described, competitively priced, and ready to accept
viewing requests. If the listings are configured correctly, leadership should then investigate renter demand, location,
pricing, and how recently the properties were listed.

The data clearly shows which properties have repeated disputes and which have no recorded viewings. It does not explain
the cause of either condition. Leadership should keep both groups visible on the dashboard and assign different
follow-up actions: quality improvement for Property IDs 1, 3, and 5, and listing activation for Property IDs 14 and 15.
